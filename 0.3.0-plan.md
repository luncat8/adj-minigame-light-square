# 0.3.0 hints and progress

Base: groups and difficulty from 0.2.0, canvas render, settings panel.

## status model

`Board.refreshStatus(b)` runs after every game trace, not during generation. `Generate.make` allocates the arrays once after groups are built. It fills:

- `b.status`: Uint8Array(n*n), per cell: 0 none, 1 partial, 2 good, 3 wrong.
- `b.found`: Uint8Array(n*n), 1 when a target cell has ever been good in this puzzle.
- `b.targetGroup`: Int16Array(n*n), group index + 1, 0 for non-targets.
- `b.groupGood`, `b.groupNeed`: per-group counts for the status line.
- `b.progress`: 0..1.
- `b.remaining`: number of good cells still needed.
- `b.wrong`: number of exact target cells that are lit with no shared channel.

Cell status:

- any-color target: 2 if lit, else 0.
- exact target: 2 if `light === mask`; 1 if `light > 0` and `(light & mask) !== 0`; 3 if `light > 0` and `(light & mask) === 0`; 0 if unlit.
- non-target: 0.

`found` is set to 1 for a target cell when its status becomes 2. It is never cleared until a new puzzle. `b.preview` is a boolean, default false; while it is true, `found` is not updated. The solution preview sets it.

Group score is `good + 0.5 * partial`, capped at `need`; group progress is score / need. Overall progress is the average group progress. A group with `need` good cells is 1. Wrong cells do not reduce a satisfied group; they only affect the hint text.

## panel

The panel gains three checkboxes:

- `#hintGood` — `Good / partial cells`, default on.
- `#hintFound` — `Discovered cells`, default on.
- `#hintTargets` — `Target cells`, default on, master toggle.

`Game.hints` holds the three booleans. `Game.setHint(name, value)` updates, calls `UI.sync`, and refreshes status. `hintTargets` off disables the other two checkboxes; the checkboxes do not change the puzzle.

## render

`Renderer.draw` receives `hints` and reads `b.status`, `b.found`, `b.targetGroup`.

- Target cells: a diamond outline in the required color for exact groups, white for any-color groups, when `hintTargets` is on. A small group number (`1`..`3`) is drawn in the top-left corner. When `hintGood` is on, a good diamond is filled and gets a check mark.
- Good: bright fill plus a check mark; distinct shape, not color alone.
- Partial: amber half-fill or dashed outline.
- Wrong: red dashed outline with a small slash.
- Found: a small dot in the top-right corner, muted cyan; brighter if the cell is currently good.
- Non-target cells: no status overlay.

`hintTargets` off hides every target overlay: diamonds, group numbers, status, and found dots. `hintGood` off leaves target diamonds as outlines and hides good/partial/wrong overlays. `hintFound` off hides found dots. The beam and cell lighting stay visible in all cases.

Shapes carry the meaning: filled diamond = good, dashed = partial, slash = wrong, dot = found. Color is secondary. Hint overlays are thin outlines and small shapes so they do not overpower the additive beam and glass tiles. Group labels come from a preallocated `['', '1', '2', '3']` lookup; no string building in the frame loop.

## status line

`Game.refresh` builds a one-line status:

- unsolved: `groups 2/3   67%   g1 1/2  g2 1/1   need 2   1 wrong   laser 7   d 0.50`
- solved: `SOLVED   100%   laser 7   d 0.50`

The renderer draws it at the top-left. The static controls line is shortened to `wheel/drag rotate   A/D laser   N new`; the panel owns the rest.

## validation

L0: `node --check js/board.js js/render.js js/ui.js js/main.js`.

L1: `node experiments/engine_smoke.js`, extended:

- exact target: good, partial (`RG` target `R`), wrong (`G` target `R`), unlit.
- any target: lit good, unlit bad.
- `found` sets on good, survives rotation, clears on new puzzle.
- group progress and overall progress for a mixed board.
- preview does not set `found`.

L2: `node experiments/dom_smoke.js` with mocked checkboxes; toggle each and draw.

Manual pass:

- toggle each checkbox; verify the matching overlay disappears without changing the puzzle.
- targets off hides all target overlays and disables good/found; targets on restores them.
- solve a puzzle; progress reaches 100% and status shows SOLVED.
- make a target partially correct; amber overlay; wrong color; red slash.
