decisions and why:
- one `index.html` + Look switch, not a second page: shares backend/view/panel/boot, no
  markup duplication, live A/B. Separate pages would split one source of truth.
- dispatcher owns `render*` names; skins expose `glass*`/`renderAlt*`: two classic scripts
  declaring the same top-level function collide in the shared lexical scope, so public
  names live in exactly one file.
- prototype skin reuses `rim.js` `drawRimItems` in the same `RIM_PAD` space: adopts the new
  items with zero duplication and identical hit-testing across skins.
- default skin stays glass: no visual change for existing users; skin is truly optional.

pitfalls: top-level `root` collided with `app.js` (renamed `rootRef`); node module exports
use different names than the skin interface, so `skinTable` maps `glass*` exports explicitly.
